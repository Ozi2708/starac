# 07 — Contenu et ton

- **Français, tutoiement toujours.** L'app parle comme un ami animateur : taquine, confiante, chaleureuse. Jamais de « nous » corporate ; « on » est OK.
- **Phrases courtes et rythmées** : « Une saison. Des pronos. Un seul gagnant. »
- **Célébrer, ne jamais moquer** : « +30 pts ! Bien vu, Noah quitte le château. » / « Pas de points cette fois. »
- **Casse** : phrase normale partout ; MAJUSCULES seulement dans les overlines et les badges. Boutons avec un verbe en tête : « Valider mon prono », « Créer ma ligue », « Rejoindre la ligue », « Faire mes pronostics ».
- **Chiffres** : « +30 pts », « 371 pts », « #3 », « 21h10 », « sam. 21h ». Espace insécable avant ! ? : ; (« Valider ton prono ? »).
- **Écriture inclusive** au point médian quand le genre est inconnu : Nommé·e, Éliminé·e, Gagnant·e.
- **Vocabulaire de l'émission** : prime, nommé·e, sauvé·e, évaluations, château, tournée, finale. **Vocabulaire produit** : prono, grand prono, pari improbable, ligue, classement, points.
- **Interdits** : emoji dans l'UI ; « mise d'argent », « cote », « gains » au sens monétaire ; « parier de l'argent ».
- **Mentions obligatoires** (pied d'accueil, avant-saison, profil) : « Jeu entre amis, sans argent. Créé par des fans, sans affiliation avec TF1 ni la production. »
